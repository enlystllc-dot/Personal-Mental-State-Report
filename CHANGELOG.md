# Mental State OS — Change log

## v2.1

- Saved form preferences continuously in browser storage, so ratings and contextual answers are pre-filled for repeat check-ins.
- Added local-day rollover: when a new local date is detected, clear the previous day's sleep duration, three-night average, sleep-quality rating, wake time, work start, last-break time and one-off note. Other ratings remain filled for review.
- Calculate time awake from a wake-up clock time, including crossing midnight; calculate work stretch and time since break from optional clock times. Add quick buttons for work start and break end.
- Keep the recommended action and its rationale ahead of scores; place detailed methodology in a collapsed section and remove repeated dopamine caveats from the report.
- Link actions to relevant research summaries; separate self-reported behavioral patterns from neurochemical hypotheses.
- Correct the physical-discomfort action mapping and remove the restlessness reassessment choice when legacy entries did not collect that rating.
- Recalculate existing stored reports with updated report logic version 3 while preserving historic check-ins and reassessment entries.
- Add a research/evidence document and clarify that the formula weights and thresholds are practical heuristics, not clinically validated measures.

## v2.0

- Added physical restlessness as a separate rating from physical sluggishness.
- Added evidence-linked interpretations, action-first report layout, time inputs, history and export support.
